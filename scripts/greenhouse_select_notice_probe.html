Greenhouse: react-select "No options" and "Loading..." notices

Reproduces the shape behind Razorpay 3468 (job-boards.greenhouse.io, 2026-10-31). A react-select filters its list as you type; when nothing matches it renders select__menu-notice--no-options "No options", whose class contains "-option". "Current Designation" on that form offers the same three career-stage values as "Current Career Stage". "Current Location" here is a remote-search widget: "No options" while the query is debounced, then "Loading...", then the results.
